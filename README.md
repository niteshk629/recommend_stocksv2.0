# recommend_stocksv2.0
Project to analyze and recommend stocks v2.0

*"Design and implement a hybrid stock recommendation system that integrates Yahoo Finance for historical analytics, Groww/Zerodha APIs for real‑time trading and mutual fund data, and sentiment analysis from news/social feeds. Build a modular pipeline with ETL, feature engineering, ML models (Prophet/XGBoost/FinBERT), and a composite scoring engine. Deploy the app with Streamlit UI (enhanced by Plotly/TradingView charts), Dockerized microservices, and a CI/CD pipeline (Jenkins/GitHub Actions). For testing, host on a minimal AWS EC2 instance (~$50/month) with Postgres for storage. Deliverables:
- Data ingestion scripts for stocks + mutual funds.
- Feature engineering for fundamentals, sentiment, and technical indicators.
- ML models trained on live + historical data with low latency inference.
- Scoring engine that outputs daily top 10 stocks + 5 mutual funds.
- Streamlit dashboard with filters, charts, and Buy/Sell integration.
- Docker + docker‑compose setup for local and cloud deployment.
- CI/CD pipeline for automated build, test, push, and deploy."*
